# 通話メモ (call-memo)

商談の通話メモ(文字起こし・要約)を保存し、Google Keepや外部AI(Claude)へ渡すための、個人利用向けスマホアプリ(PWA)です。
サーバー・ビルド・外部APIは不要で、データはスマホのブラウザ内にのみ保存されます。

## 使い方

### 基本: Pixelの内蔵機能を使う
1. 通話を録音し、Pixelの**Recorderアプリ**で文字起こし・要約を作る
2. Recorderの「共有」から本アプリへ送る(文字起こしが新規メモに取り込まれます)。または本アプリの「貼り付け」ボタンで貼り付ける
3. 要約欄にRecorderの要約を貼り付ける
4. 「Keepに共有」→ 共有先で Keep を選ぶ

### 追加機能: 外部AI(Claude)に要約を頼む
1. メモ画面の「要約の方法」で **「使わない(外部AIに依頼)」** を選ぶ
2. 「Claudeに貼り付ける内容」(要約用プロンプト + 文字起こし)が表示される
3. 「全文をコピー」(またはプロンプトのみ / 文字起こしのみ)→「Claudeを開く」で貼り付ける
4. Claudeの回答を「③ 要約」に貼り付けて保存 → 必要ならKeepに共有

要約用プロンプトは「設定」から編集できます。

## 導入(スマホで使えるようにする)

PWAのインストール・共有ターゲットは **HTTPS** が必要です。このリポジトリの内容を静的ホスティングに置いてください(GitHub Pages、Cloudflare Pages、Netlify など。ビルド不要)。

1. 公開したURLをPixelのChromeで開く
2. メニュー →「ホーム画面に追加」(インストール)
3. インストール後は、Recorderの共有先一覧に「通話メモ」が表示されます

※ 公開URLを知っている人はアプリ本体を開けますが、メモのデータは各端末内にしかありません。

ローカルでの動作確認: リポジトリ直下で `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開く。

## 制限・注意

- 共有で取り込めるのは**テキスト**のみです(音声ファイルの共有は非対応)。
- データはブラウザ内保存です。ブラウザのデータ削除や機種変更に備え、「設定 → 書き出し」で定期的にバックアップしてください。
- 通話の録音・AI処理は、相手への告知と同意を得たうえで行ってください。外部AIに貼り付けた内容は、そのサービスに送信されます。
- Recorderの日本語要約やGoogle電話の通話録音の対応状況は、機種・地域・OSバージョンによって異なります。

## ファイル構成

- `index.html` / `style.css` / `app.js` — アプリ本体
- `sw.js` / `manifest.webmanifest` — オフライン対応・インストール・共有ターゲット
- `tools/make-icons.mjs` — アイコン生成 (`node tools/make-icons.mjs`)

## GitHub Pages での公開

`main` にpushすると `.github/workflows/pages.yml` が自動でデプロイします。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開URL: `https://<ユーザー名>.github.io/call-memo/`
